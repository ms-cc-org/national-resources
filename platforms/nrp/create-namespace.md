# Create Namespace
1. Once you are logged in to the Element, you’ll automatically join the Nautilus General channel and News Channel. Currently, the general channel is named “Nautilus Support”.
2. On the general channel, send a message to create a namespace.
3. Let the support team know the desired namespace for your group (usually the department name). You can use lowercase letters, numbers, and dashes only. Choose clear, descriptive names (avoid generic ones like kubernetes-ai, testing-group, llm-access). To see the existing names for reference, please visit this [visualization tree](https://nrp.ai/viz/namespaces/). For eg; To create namespace for MS-CC projects, it would be i2-mscc-projectname. i2(Internet2) is the Organization Name
4. Once your namespace has been created by the support team, you can now access your namespace.

# Access Namespace
1. If you have become a namespace admin, you can start creating your own namespaces at this time by going to the [Namespaces manager](https://nrp.ai/namespaces/) section on the portal. You can add other users on the same page after they have logged in to the portal.
2. If you got added to a namespace as a user, you can verify it by going to the [Namespaces manager](https://nrp.ai/namespaces/) tab after logging in to the portal. The namespaces you’re a member of will be marked in bold.
