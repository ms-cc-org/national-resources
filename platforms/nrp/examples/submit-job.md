# Run Monte Carlo Pi Estimation on NRP Kubernetes Cluster

Once you are logged in to the NRP cluster and can run the kubernetes commands, follow the steps below to run monte_carlo_pi_estimation. 

1. Submit the Job
Submit the job
```
$ kubectl apply -f pi-job.yaml
```

2. Check Job StatusWatch the pod transition from ContainerCreating $\rightarrow$ Running $\rightarrow$ Completed:

```
$ kubectl get pods -n i2-mscc-nrp-test
NAME                       READY   STATUS      RESTARTS   AGE
monte-carlo-pi-job-g22zx   0/1     Completed   0          15s

```

3. Read Output Logs
Retrieve stdout output generated by your Python code:

```
$ kubectl logs -l job-name=monte-carlo-pi-job -n i2-mscc-nrp-test
--> Starting Monte Carlo Pi calculation with 10,000,000 samples...
--------------------------------------------------
Calculated Pi Estimate : 3.141743
Actual Value of Pi     : 3.141593
Execution Time         : 1.868 seconds
--------------------------------------------------
```

4. Clean Up
When done, clean up the resources:

```
$ kubectl delete -f pi-job.yaml 
job.batch "monte-carlo-pi-job" deleted from i2-mscc-nrp-test namespace
```

Note: For more information on batch jobs visit [NRP Batch Jobs](https://nrp.ai/documentation/userdocs/tutorial/jobs/)
