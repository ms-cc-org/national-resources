# Login to Element

1. Navigate to [web version of Element Client](https://element.nrp-nautilus.io/#/register)
2. Use “Host Account” matrix.nrp-nautilus.io
3. Create an account by entering a desired username, password and email.
4. After that you’ll get an account of the form @username:matrix.nrp-nautilus.io, which you can use to join rooms in any federated [matrix] resource, including the original https://matrix.org.
5. Click the explore rooms button. Check that you’re exploring the NRP server (matrix.nrp-nautilus.io). You’ll automatically join the Nautilus General channel and the News channel. For all other homeservers including Matrix.org, you can directly access and join the NRP Matrix Space (or join using the address #nrp:matrix.nrp-nautilus.io) for all channels.
6. Once you are logged in to Element, ask the support team to [create the Namespace](create-namespace.md).
